# 🧩 SudoPlay

<div align="center">
  <h3>An exquisite, high-performance Sudoku suite built entirely in Vanilla JavaScript.</h3>
  <p>Play, learn, and solve with a stunning glassmorphic UI, dynamic rules visualizer, and an instant auto-solver.</p>
</div>

<br/>

## ✨ Features

- **🎨 Modern Glassmorphic UI:** A visually striking interface featuring floating elements, smooth transitions, a dynamic 3D hero board, and seamless **Light / Dark Mode** toggling.
- **🎮 Fully Interactive Gameplay:** Play Sudoku smoothly with full keyboard navigation (arrow keys), numpad support, pencil notes, and an undo feature.
- **🧠 Smart Hint Engine:** Stuck? Get logical, step-by-step reasoning hints (e.g., Hidden Singles, Naked Pairs) that explain your next best move instead of just giving you the answer.
- **🎬 Animated Rules Visualizer:** Learn how to play with a mini dual-board setup that cycles through the rules, visually demonstrating incorrect vs. correct moves side-by-side.
- **💡 Sudoku Fun Facts:** Hover over the facts card to discover interesting trivia and history about Sudoku.

- **📊 LocalStorage Analytics:** Track your wins, losses, difficulty levels, and speed natively in your browser.

## 🛠️ Tech Stack

- **HTML5:** Semantic structuring and layout.
- **CSS3:** Custom properties (variables), Flexbox/Grid layouts, glassmorphism, responsive design, and CSS animations.
- **Vanilla JavaScript:** 100% pure JS logic with zero external libraries or dependencies. State management, solving algorithms, and DOM manipulation built from scratch.

## 🚀 Getting Started

SudoPlay is a static web application that runs entirely in your browser. No build steps, no Node modules, and no servers required!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sree-hari-v/sudoplay.git
   ```
2. **Navigate to the folder:**
   ```bash
   cd sudoplay
   ```
3. **Run the app:**
   Simply double-click `index.html` to open it in your favorite modern web browser (Chrome, Firefox, Safari, Edge).

## 🎯 How to Play

1. **Objective:** Fill every cell in the 9x9 grid so that every row, column, and 3x3 box contains the digits 1 through 9 exactly once.
2. **Notes:** Use the **Notes (Pencil)** toggle to jot down possible numbers in empty cells.
3. **Difficulty:** Choose between Easy, Medium, Hard, and Expert presets.
